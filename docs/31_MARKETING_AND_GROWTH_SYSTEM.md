# 48. Definition of Done

Marketing System считается завершенной если:

* работает FREE → PRO воронка;
* работает система продлений;
* работают промокоды;
* работает email-маркетинг;
* работает партнерская программа;
* работает аналитика роста.

---

# 49. Ограничение MVP

Реклама сторонних сервисов запрещена.

---

Продвигаются только собственные продукты платформы.

---

# 50. Главная цель

Каждый пользователь FREE версии должен понимать преимущества PRO, а система должна максимально эффективно превращать пользователей в платящих клиентов и удерживать их на протяжении многих лет.
