# 14_PRO_PLUGIN_SPEC.md

# PROJECT B

WordPress Plugin PRO

Название:

Ozon for WooCommerce PRO

Версия:

1.0.0

Статус: Technical Specification

---

# 1. Назначение

PRO является расширением FREE.

---

FREE обязателен.

---

PRO не работает самостоятельно.

---

Требование:

```text
FREE Plugin Installed
+
FREE Plugin Active
+
Valid License
```

---

# 2. Основная цель

Автоматизация процессов.

---

PRO не заменяет FREE.

---

PRO расширяет FREE.

---

# 3. Возможности PRO

Добавляются:

* лицензирование;
* массовая выгрузка;
* массовая проверка статусов;
* очередь задач;
* автоматическое обновление цен;
* автоматическое обновление остатков;
* журнал операций;
* автоматическая синхронизация.

---

# 4. Архитектура

```text
FREE
│
├── Ozon_Client
├── Ozon_Category_Manager
├── Ozon_Attributes_Manager
├── Ozon_Product_Exporter
└── Ozon_Status_Checker

PRO
│
├── Ozon_License_Manager
├── Ozon_Queue_Manager
├── Ozon_Bulk_Manager
├── Ozon_Sync_Manager
├── Ozon_Logger
└── Ozon_Updater
```

---

# 5. Проверка лицензии

При активации PRO:

```text
License Key
↓
License Server
↓
Validation
↓
Activation
```

---

Проверяется:

* лицензия;
* срок действия;
* домен.

---

# 6. Лицензионная модель

Одна лицензия:

```text
1 домен
```

---

Тарифы:

```text
PRO 1 Month

PRO 6 Months

PRO 12 Months
```

---

# 7. Статусы лицензии

Поддерживаются:

```text
active

expired

blocked

invalid

suspended
```

---

# 8. Настройки PRO

Новый раздел:

```text
WooCommerce → Ozon → PRO
```

---

Отображает:

* ключ лицензии;
* статус;
* срок действия;
* зарегистрированный домен.

---

# 9. Массовая выгрузка

Добавляется действие:

```text
Выгрузить в Ozon
```

---

Работает из списка товаров.

---

Поддержка:

* одного товара;
* нескольких товаров;
* всех выбранных товаров.

---

# 10. Массовая проверка статусов

Добавляется действие:

```text
Проверить статус
```

---

Все товары помещаются в очередь.

---

# 11. Повтор ошибок

Добавляется действие:

```text
Повторить выгрузку
```

---

Обрабатываются только товары:

```text
status = error
```

---

# 12. Очередь задач

Используется:

```text
Action Scheduler
```

---

Собственная очередь запрещена.

---

# 13. Работа очереди

Каждый товар:

отдельная задача.

---

Пример:

```text
Task #1
Product 100

Task #2
Product 101

Task #3
Product 102
```

---

Запрещено:

выгружать сотни товаров одним запросом.

---

# 14. Страница очереди

Меню:

```text
WooCommerce → Ozon Queue
```

---

Отображает:

* всего задач;
* ожидают;
* выполняются;
* завершены;
* ошибки.

---

# 15. Действия очереди

Кнопки:

```text
Проверить статусы

Повторить ошибки

Очистить завершенные
```

---

# 16. Автоматическое обновление остатков

Отслеживаются изменения:

```text
stock_quantity
```

---

После изменения:

товар помещается в очередь.

---

# 17. Автоматическое обновление цен

Отслеживаются изменения:

```text
regular_price

sale_price
```

---

После изменения:

товар помещается в очередь.

---

# 18. Автоматическая синхронизация

Периодические задачи:

```text
каждые 15 минут

каждый час

каждые 6 часов

каждые 24 часа
```

---

Настраиваются пользователем.

---

# 19. Журнал операций

Меню:

```text
WooCommerce → Ozon Logs
```

---

Отображаются:

* дата;
* действие;
* товар;
* результат;
* сообщение.

---

# 20. Типы событий

Логируются:

* экспорт;
* обновление цены;
* обновление остатков;
* проверка статуса;
* ошибки API;
* ошибки лицензии.

---

# 21. Автоматическая деактивация

Если лицензия истекла:

PRO-функции отключаются.

---

FREE продолжает работать.

---

# 22. Что происходит после окончания лицензии

Сохраняются:

* настройки;
* очередь;
* логи;
* данные товаров.

---

Блокируются:

* новые массовые операции;
* автоматическая синхронизация.

---

# 23. Обновления PRO

Источник:

License Server

---

WordPress.org не используется.

---

# 24. Проверка обновлений

Периодичность:

```text
1 раз в сутки
```

---

Проверяется:

* новая версия;
* активность лицензии.

---

# 25. Логирование лицензии

Фиксируются:

* активация;
* деактивация;
* истечение;
* ошибки проверки.

---

# 26. Подготовка к PORTAL

Все проверки лицензий должны выполняться через API.

---

Запрещено:

хранить логику лицензирования только внутри плагина.

---

Источник истины:

```text
License Server
```

---

# 27. Безопасность

Все запросы лицензии:

```text
HTTPS only
```

---

Все ответы:

проверка подписи.

---

Все ключи:

санитизация и валидация.

---

# 28. Ограничения PRO

Запрещено:

* создавать собственную очередь;
* обходить Action Scheduler;
* хранить лицензии в открытом виде;
* выполнять массовые операции без очереди.

---

# 29. Definition of Done

PRO считается завершенным если:

* работает лицензирование;
* работает массовая выгрузка;
* работает массовая проверка;
* работает очередь;
* работает автосинхронизация;
* работает журнал операций;
* работает обновление PRO через сервер лицензий.

---

# 30. Результат проекта

Пользователь способен управлять сотнями и тысячами товаров Ozon напрямую из WooCommerce без ручных операций, используя лицензируемую коммерческую версию плагина.
