# 20_YOOKASSA_BILLING_SPEC.md

# PROJECT C

YooKassa Billing System

Версия: 1.0.0

Статус: Billing Specification

---

# 1. Назначение

Документ описывает систему приема платежей.

---

Используется для:

* покупки лицензий;
* продления лицензий;
* управления подписками;
* учета платежей;
* формирования финансовой статистики.

---

# 2. Платежный провайдер

Версия 1.0:

```text
ЮKassa
```

---

Будущие версии:

```text
Stripe

CloudPayments

Robokassa
```

---

# 3. Основная схема оплаты

```text
Клиент
    ↓
Выбор тарифа
    ↓
Создание платежа
    ↓
ЮKassa
    ↓
Webhook
    ↓
License Server
    ↓
Создание лицензии
```

---

# 7. Создание платежа

Endpoint:

```text
POST /payments/create
```

---

Запрос:

```json
{
  "product":"ozon_pro",
  "plan":"pro_12_months"
}
```

---

# 8. Ответ создания платежа

```json
  "data": {

  }
}
```

# 9. Платежные статусы

Поддерживаются:

```text

waiting

paid

canceled

failed

refunded
```

---

# 10. Источник истины

Единственный источник подтверждения оплаты:

```text
Webhook ЮKassa
```

---

Нельзя считать платеж успешным:

```text
по redirect URL

по кнопке браузера

по параметрам URL
```

---

# 11. Webhook URL

```text

```

---

# 12. Поддерживаемые события

```text

```

# 13. Обработка payment.succeeded

После получения:

```text
Проверка подписи
↓
Проверка платежа
↓
Сохранение платежа
↓
Создание лицензии
↓
Email клиенту
```

Поддерживаются:

```text

```

---

Частичный возврат:


# 36. Ограничения

Система не должна:

```text
создавать лицензии без оплаты

доверять redirect URL

создавать дубликаты лицензий

создавать дубликаты платежей
```

---

# 37. Definition of Done

Billing System считается завершенным если:

* создаются платежи;
* работает ЮKassa;
* работают webhook;
* создаются лицензии;
* работают продления;
* работают возвраты;
* ведется финансовый учет;
* отправляются уведомления.

---

# 38. Главная цель

После успешной оплаты клиент должен автоматически получить рабочую лицензию, доступ в личный кабинет и возможность скачать PRO без участия администратора.
