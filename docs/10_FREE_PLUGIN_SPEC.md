# 1. Назначение

Плагин предназначен для публикации товаров WooCommerce в Ozon через Seller API.

FREE версия должна обеспечивать:

* подключение к Ozon;
* выбор типа товара;
* заполнение атрибутов;
* ручную выгрузку товаров;
* проверку статусов.

Без автоматизации.

Без лицензирования.

Без очередей.

# 26. Definition of Done

FREE считается завершенным если:

* подключается к Ozon;
* получает категории;
* получает атрибуты;
* сохраняет атрибуты;
* формирует товар;
* отправляет товар;
* получает статус;
* отображает статус в WooCommerce.

---

# 27. Результат проекта

Пользователь способен без сторонних сервисов:

1. Подключить Ozon API.
2. Выбрать тип товара.
3. Заполнить характеристики.
4. Отправить товар в Ozon.
5. Контролировать статус публикации прямо из WooCommerce.
