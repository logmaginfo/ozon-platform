Версия: 1.0.0

Статус: Functional Specification

---

# 1. Назначение

Admin Panel является центральной панелью управления платформой.

---

Используется для:

* управления лицензиями;
* управления клиентами;
* управления платежами;
* управления доменами;
* управления обновлениями;
* анализа продаж.

---

# 40. Производительность

Панель должна поддерживать:

```text
100 000 клиентов

500 000 лицензий

миллионы API запросов
```

---

без деградации интерфейса.

---

# 41. Definition of Done

Admin Panel считается завершенной если администратор способен:

* видеть все продажи;
* видеть все лицензии;
* видеть все платежи;
* видеть все домены;
* управлять клиентами;
* выпускать обновления;
* контролировать подписки;
* анализировать бизнес.

---

# 42. Главная цель

Владелец платформы должен иметь возможность управлять всей экосистемой Ozon Platform из одной панели без доступа к базе данных и без ручного вмешательства в работу клиентов.
