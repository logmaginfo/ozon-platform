# OZON_PLATFORM

Версия: 1.1

Статус: Approved Draft

---

# 1. Назначение продукта

OZON_PLATFORM — это коммерческая экосистема для интеграции интернет-магазинов WooCommerce с маркетплейсом Ozon.

Платформа должна позволять владельцу интернет-магазина:

* подключить Ozon Seller API;
* подготовить товары к публикации;
* выгружать товары в Ozon;
* отслеживать статусы публикации;
* управлять товарами напрямую из WooCommerce.

Платформа должна обеспечивать простое подключение, минимальные требования к пользователю и возможность дальнейшего масштабирования бизнеса через подписочную модель.

---

# 2. Миссия проекта

Сделать публикацию товаров в Ozon настолько простой, чтобы любой владелец WooCommerce-магазина мог начать работу без программиста и без использования сторонних сервисов.

---

# 3. Экосистема продукта

Платформа состоит из трех связанных проектов.

---

## PROJECT A

### WordPress Plugin FREE

Бесплатная версия плагина.

Назначение:

* привлечение пользователей;
* знакомство с продуктом;
* демонстрация возможностей интеграции.

Функции:

* подключение к Ozon API;
* получение категорий;
* получение атрибутов;
* публикация отдельных товаров;
* проверка статусов;
* история операций;
* колонка Ozon в списке товаров.

---

## PROJECT B

### WordPress Plugin PRO

Платное расширение FREE версии.

Работает только при установленном FREE плагине.

Назначение:

* автоматизация процессов;
* экономия времени пользователя;
* коммерческая монетизация продукта.

Функции:

* массовая выгрузка;
* массовая проверка статусов;
* очереди задач;
* автоматическая синхронизация;
* обновление цен;
* обновление остатков;
* импорт заказов;
* журнал операций.

---

## PROJECT C

### License Portal

Веб-портал лицензирования.

Назначение:

* продажа лицензий;
* прием платежей;
* продление подписок;
* управление лицензиями;
* личный кабинет клиентов;
* административный контроль платформы.

---

# 4. Бизнес-модель

Основная модель монетизации:

FREE
↓
PRO
↓
Продление лицензии
↓
Регулярный доход

Источник дохода:

подписка на PRO-версию плагина.

---

# 5. Лицензионная модель

Основное правило:

Одна лицензия = один домен.

Каждый сайт требует отдельную лицензию.

Лицензия привязывается к:

* домену;
* email владельца.

---

Платформа использует три основных тарифа.

Тариф №1

Лицензия PRO на 1 месяц

Ограничение:

1 домен

---

Тариф №2

Лицензия PRO на 6 месяцев

Ограничение:

1 домен

---

Тариф №3

Лицензия PRO на 12 месяцев

Ограничение:

1 домен

---

# 7. Клиентский портал

Каждый клиент получает доступ в личный кабинет.

Доступные возможности:

* просмотр лицензий;
* просмотр доменов;
* скачивание PRO версии;
* продление лицензий;
* просмотр платежей;
* управление своими сайтами.

---

# 8. Административный портал

Администратор платформы должен иметь полный контроль над системой.

Администратор должен видеть:

* всех клиентов;
* все лицензии;
* все домены;
* все платежи;
* все продления;
* общую выручку;
* истекающие лицензии;
* ошибки активации.

Администратор должен иметь возможность:

* создавать лицензии;
* продлевать лицензии;
* блокировать лицензии;
* удалять лицензии;
* просматривать историю операций.

---

# 9. Платежная система

Основная платежная система:

ЮKassa.

Поддерживаемые способы оплаты:

* банковские карты;
* СБП;
* ЮMoney.

После успешной оплаты лицензия создается автоматически.

# 13. Критерии успеха

Пользователь должен иметь возможность:

* подключить Ozon API менее чем за 5 минут;
* опубликовать товар без сторонних сервисов;
* контролировать статус товара из WooCommerce;
* перейти на PRO без потери данных;
* продлить лицензию за несколько кликов.

---

# 14. Главная цель проекта

Создать надежную коммерческую платформу для WooCommerce и Ozon, которая приносит регулярный доход через подписочную модель и при этом остается простой для пользователей и поддержки.
