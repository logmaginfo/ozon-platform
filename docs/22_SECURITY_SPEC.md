# 22_SECURITY_SPEC.md

# PROJECT C

Security Specification

Версия: 1.0.0

Статус: Security Architecture Specification

---

# 1. Назначение

Документ определяет требования безопасности для:

* FREE Plugin
* PRO Plugin
* License Server
* Customer Portal
* Admin Panel
* Billing System

---

# 2. Основной принцип

Источник истины:

```text
License Server
```

---

Плагин не является источником истины.

---

Любая лицензия может быть подтверждена только сервером.

---

# 3. Модель угроз

Необходимо защищаться от:

```text
Кражи лицензий

Подмены доменов

Распространения PRO ZIP

Подделки API запросов

Подделки webhook

Брутфорса

Утечки базы данных
```

---

# 4. HTTPS

Все сервисы работают только через:

```text
HTTPS
```

---

HTTP запрещен.

---

# 5. TLS

Минимальная версия:

```text
TLS 1.2
```

---

Рекомендуется:

```text
TLS 1.3
```

---

# 6. Защита License API

Все запросы:

```text
Rate Limit
```

---

По IP.

---

По License Key.

---

# 7. Ограничение запросов

Публичный API:

```text
60 запросов / минута
```

---

Admin API:

```text
300 запросов / минута
```

---

# 8. Логирование запросов

Каждый запрос сохраняется:

```text
api_requests
```

---

Фиксируется:

```text
IP

Endpoint

User Agent

Response Code

Timestamp
```

---

# 9. License Key

Полный ключ не отображается.

---

Пример:

```text
OZON-AB12-****-****-GH78
```

---

# 10. Хранение лицензий

License Key хранится:

```text
encrypted
```

---

Открытый ключ в БД запрещен.

---

# 11. Генерация лицензий

Используется:

```text
Cryptographically Secure Random
```

---

Запрещено:

```text
Последовательные номера

Инкрементные ключи
```

---

# 12. Проверка лицензии

Проверяется:

```text
License

Status

Expiration

Domain
```

---

Все проверки выполняются на сервере.

---

# 13. Привязка к домену

Лицензия работает только на:

```text
1 домен
```

---

# 14. Нормализация домена

Перед проверкой:

```text
www.site.ru

site.ru
```

---

Считаются одним доменом.

---

# 15. Ограничение смены домена

Версия 1.0:

```text
5 смен в месяц
```

---

# 16. Кэш лицензии

Плагин хранит локальный кэш:

```text
24 часа
```

---

Для снижения нагрузки.

---

# 17. Потеря связи с сервером

Если License Server недоступен:

```text
Использовать последний валидный кэш
```

---

Максимум:

```text
7 дней
```

---

После:

```text
License Verification Required
```

---

---

# 19. Refresh Token

Используется:


# 48. Антипиратская модель

Даже если ZIP распространен:

```text

```

---

# 49. Definition of Done

Security Layer считается завершенным если:

* защищены лицензии;
* защищены домены;
* защищены платежи;
* защищены обновления;
* защищен Customer Portal;
* защищен Admin Panel;
* защищен License API;
* ведется аудит действий.

---

# 50. Главная цель

Любая попытка использовать PRO без действующей лицензии, подделать платеж, подменить домен или обойти сервер лицензирования должна приводить к блокировке функционала и фиксации события в системе аудита.
