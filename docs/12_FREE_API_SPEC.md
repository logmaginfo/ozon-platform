# 12_FREE_API_SPEC.md

# PROJECT A

WordPress Plugin FREE

Версия: 1.0.0

Статус: API Integration Specification

---

# 1. Назначение документа

Документ определяет правила взаимодействия плагина с Ozon Seller API.

Документ описывает:

* API-клиент;
* точки интеграции;
* структуру запросов;
* обработку ошибок;
* кэширование;
* ограничения.

---

# 2. Основной принцип

Плагин не должен зависеть от конкретной версии API.

---

Все вызовы должны выполняться через:

```text
Ozon_Client
```

---

Запрещено выполнять HTTP-запросы напрямую из:

* метабоксов;
* AJAX-обработчиков;
* страниц настроек;
* шаблонов.

---

# 3. Архитектура API

Все обращения проходят через:

```text
Admin UI
↓
Service Layer
↓
Ozon_Client
↓
Ozon Seller API
```

---

# 4. Авторизация

Источник данных:

```text
ozon_client_id
ozon_api_key
```

---

Источник хранения:

```text
wp_options
```

---

При каждом запросе используются:

* Client ID
* API Key

---

# 5. Проверка подключения

Используется для:

* сохранения настроек;
* диагностики;
* проверки доступа.

---

Результат:

```text
success
```

или

```text
error
```

---

# 6. Категории

Назначение:

получение дерева категорий Ozon.

---

Результат:

```text
Категория
↓
Подкатегория
↓
Тип товара
(type_id)
```

---

После получения:

строится локальный индекс.

---

Источник хранения:

```text
ozon_categories
```

---

# 7. Получение характеристик

Вход:

```text
type_id
```

---

Результат:

список атрибутов.

---

Каждый атрибут содержит:

* id
* название
* тип
* обязательность
* множественность
* справочник значений

---

# 8. Получение справочников

Если атрибут использует список значений:

плагин выполняет дополнительный запрос.

---

Результат сохраняется в кэш.

---

Источник хранения:

```text
ozon_dictionary_cache
```

---

# 9. Формирование товара

Источник данных:

WooCommerce

*

атрибуты Ozon

*

type_id

---

Результат:

единая структура товара.

---

Перед отправкой выполняется валидация.

---

# 10. Валидация

Проверяются:

* обязательные атрибуты;
* SKU;
* цена;
* изображения;
* type_id.

---

Если проверка не пройдена:

отправка запрещается.

---

# 11. Создание товара

После успешной проверки:

формируется JSON.

---

JSON передается в API.

---

Результат:

идентификатор операции.

---

Сохраняется:

```text
_ozon_task_id
```

---

# 12. Проверка статуса

Вход:

```text
task_id
```

---

Результат:

текущий статус обработки.

---

Поддерживаемые состояния:

* pending
* processing
* published
* error

---

# 13. Ошибки API

Все ошибки должны сохраняться.

---

Источник:

```text
_ozon_error
```

---

Пример:

```text
Brand is required
```

---

# 14. Повторный запрос

Если API недоступен:

разрешается одна автоматическая повторная попытка.

---

Если повторная попытка не удалась:

возвращается ошибка.

---

# 15. Таймауты

Рекомендуемый таймаут:

```text
30 секунд
```

---

Запрещено использовать бесконечное ожидание.

---

# 16. Ограничение запросов

Плагин обязан учитывать ограничения Ozon API.

---

При получении ограничений:

запрос прекращается.

---

Ошибка сохраняется в лог.

---

# 17. Кэширование категорий

Категории не должны запрашиваться при каждом открытии страницы.

---

Источник:

```text
ozon_categories
```

---

Обновление:

только вручную.

---

# 18. Кэширование атрибутов

Характеристики категории сохраняются локально.

---

Источник:

```text
ozon_attributes_cache
```

---

# 19. Кэширование справочников

Справочники значений сохраняются локально.

---

Источник:

```text
ozon_dictionary_cache
```

---

# 20. Логирование API

Каждый запрос обязан логироваться.

---

Фиксируется:

* операция;
* дата;
* результат;
* код ответа;
* сообщение ошибки.

---

# 21. Формат результата клиента

Каждый метод клиента возвращает единый формат.

Успех:

```php
[
    'success' => true,
    'data' => []
]
```

---

Ошибка:

```php
[
    'success' => false,
    'message' => 'Error text'
]
```

---

# 22. Исключения

Внешний код не должен получать необработанные исключения.

---

Все исключения перехватываются внутри:

```text
Ozon_Client
```

---

# 23. Обновление API

При изменении Seller API:

изменения выполняются только внутри:

```text
Ozon_Client
```

---

Остальная система не должна изменяться.

---

# 24. Подготовка к PRO

Все методы FREE должны быть совместимы с будущими очередями PRO.

---

PRO использует тот же API-клиент.

---

Запрещено создавать отдельный API-клиент для PRO.

---

# 25. Definition of Done

API слой считается завершенным если:

* выполняется подключение;
* получаются категории;
* получаются атрибуты;
* получаются справочники;
* формируется товар;
* выполняется отправка;
* выполняется проверка статуса;
* ошибки корректно обрабатываются.

---

# 26. Главный принцип

Любое изменение Ozon API должно требовать изменения только одного компонента:

```text
Ozon_Client
```

а не всей архитектуры плагина.
