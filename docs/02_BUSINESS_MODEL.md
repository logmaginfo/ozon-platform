# 1. Назначение бизнес-модели

Основная цель проекта:

Создать стабильный и прогнозируемый источник регулярного дохода через продажу лицензий на PRO-функции платформы.

Модель дохода:

FREE
↓
PRO
↓
Продление лицензии
↓
Регулярная выручка

---

# 2. Стратегия продукта

FREE версия не предназначена для заработка.

FREE версия предназначена для:

* привлечения пользователей;
* демонстрации возможностей продукта;
* формирования доверия;
* генерации переходов в PRO.

Основной доход приносит только PRO.

---

FREE Plugin

Бесплатно

---

PROJECT B

PRO Plugin

По лицензии

---

PROJECT C

Portal

Входит в стоимость лицензии

---

# 4. FREE версия

FREE должна быть полностью рабочим продуктом.

Пользователь обязан получить реальную пользу даже без покупки PRO.

FREE включает:

✔ Настройки Ozon API

✔ Загрузка категорий

✔ Загрузка атрибутов

✔ Работа с type_id

✔ Проверка обязательных полей

✔ Ручная отправка товара

✔ Проверка статуса товара

✔ История операций

✔ Колонка Ozon

---

FREE не включает:

✖ Массовую выгрузку

✖ Очереди

✖ Автоматические проверки

✖ Обновление цен

✖ Обновление остатков

✖ Импорт заказов

✖ Планировщик задач

---

# 5. Реклама PRO внутри FREE

Реклама должна быть ненавязчивой.

Основная задача рекламы:

Показать преимущества PRO.

Размещение:

* Страница настроек
* Список товаров
* Массовые действия
* Отчеты
* Очереди

Запрещено:

* блокировать работу FREE;
* скрывать данные;
* навязчивые всплывающие окна.

---

# 6. PRO версия

PRO является дополнением к FREE.

PRO не работает без установленного FREE.

---

PRO включает:

✔ Массовую выгрузку товаров

✔ Массовую проверку статусов

✔ Очередь задач

✔ Action Scheduler

✔ Автоматическую синхронизацию

✔ Обновление остатков

✔ Обновление цен

✔ Импорт заказов

✔ Автоматическую обработку ошибок

✔ Расписание задач

✔ Журнал операций

---

# 7. Лицензионная модель

Основное правило:

Одна лицензия = один домен.

Каждый сайт требует отдельную лицензию.

Примеры:

site1.ru = лицензия

site2.ru = отдельная лицензия

shop.example.com = отдельная лицензия

---

# 9. Продление лицензии

Пользователь может продлить лицензию в любое время.

При продлении:

оставшийся срок не теряется.

Новый период добавляется к текущему сроку.

Пример:

Осталось:

20 дней

Покупка:

12 месяцев

Результат:

12 месяцев + 20 дней

---

# 10. Истечение лицензии

После окончания лицензии:

PRO-функции отключаются.

FREE-функции продолжают работать.

Данные пользователя не удаляются.

Настройки пользователя не удаляются.

История пользователя не удаляется.

---

Автоматические уведомления отправляются:

За 14 дней

За 7 дней

За 1 день

В день окончания

Через 7 дней после окончания

# 14. Личный кабинет клиента

Клиент должен видеть:

* свои лицензии;
* свои домены;
* дату окончания лицензии;
* историю платежей;
* кнопку продления;
* кнопку скачивания PRO.

---

# 15. Кабинет администратора

Администратор должен полностью контролировать систему.

Основные разделы:

Dashboard

Клиенты

Лицензии

Домены

Платежи

Подписки

Статистика

Уведомления

---

# 16. Основные показатели администратора

Администратор должен видеть:

* количество клиентов;
* количество активных лицензий;
* количество истекающих лицензий;
* количество просроченных лицензий;
* продажи за день;
* продажи за месяц;
* продажи за год;
* общую выручку.

---

# 17. Действия администратора

Администратор может:

* создавать лицензии;
* продлевать лицензии;
* менять срок действия;
* блокировать лицензии;
* разблокировать лицензии;
* удалять лицензии;
* менять домен лицензии;
* просматривать историю лицензии.

---

# 18. Политика возвратов

Возврат осуществляется вручную через административный кабинет.

После возврата:

лицензия автоматически деактивируется.

---

# 19. Обновления

FREE:

обновляется через WordPress.org

---

PRO:

обновляется через собственный сервер обновлений.

---

# 20. Главная бизнес-цель

Максимальное количество пользователей FREE.

Максимально простой переход в PRO.

Максимально высокий процент продления лицензий.

Максимально автоматизированная система продаж.

---

# 21. Definition of Success

Успешной считается модель, если:

* пользователь получает пользу от FREE;
* пользователь понимает ценность PRO;
* переход на PRO занимает менее 5 минут;
* продление лицензии занимает менее 2 минут;
* большинство продаж и продлений выполняется автоматически без участия администратора.
