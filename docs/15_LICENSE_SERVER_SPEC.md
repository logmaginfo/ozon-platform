# 15_LICENSE_SERVER_SPEC.md

# PROJECT C

License Server + Customer Portal + Admin Panel

Версия: 1.0.0

Статус: Technical Specification

---

# 1. Назначение

PROJECT C является центральной системой платформы.

---

Отвечает за:

* продажу лицензий;
* проверку лицензий;
* выдачу обновлений;
* продление подписок;
* управление клиентами;
* управление доменами;
* интеграцию ЮKassa.

---

# 2. Основные пользователи

### Клиент

Покупает лицензию.

Использует PRO.

---

### Администратор

Управляет всей системой.

---

# 15. License API

Должны существовать методы:

```text
activate

validate

deactivate

renew

check-update
```

---

# 16. Activate API

Вход:

```json
{
  "license_key":"...",
  "domain":"example.com"
}
```

---

Результат:

```json
{
  "success":true
}
```

---

# 17. Validate API

Используется PRO плагином.

---

Проверяет:

* ключ;
* домен;
* срок действия.

---

# 18. Deactivate API

Освобождает домен.

---

Используется:

при переносе сайта.

---

# 19. Renew API

Используется после оплаты продления.

---

Продлевает:

дату окончания лицензии.

---

# 20. Update API

Используется PRO плагином.

---

Возвращает:

* новую версию;
* changelog;
* ссылку на ZIP.

# 35. Definition of Done

PROJECT C считается завершенным если:

* работает покупка;
* работает ЮKassa;
* создаются лицензии;
* работает личный кабинет клиента;
* работает кабинет администратора;
* работает API лицензий;
* работает выдача обновлений PRO.

---

# 36. Главная цель системы

Владелец платформы должен иметь возможность полностью контролировать:

* продажи;
* лицензии;
* клиентов;
* домены;
* обновления;

из единой административной панели без ручного вмешательства в процесс обслуживания клиентов.
