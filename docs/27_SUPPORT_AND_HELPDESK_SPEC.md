# 27_SUPPORT_AND_HELPDESK_SPEC.md

# OZON PLATFORM v1.1

Support & Helpdesk Specification

Версия: 1.0.0

Статус: Customer Support Specification

---

# 1. Назначение

Документ определяет:

* систему поддержки клиентов;
* обработку обращений;
* тикеты;
* базу знаний;
* SLA поддержки;
* историю взаимодействия с клиентами.

---

# 2. Главная цель

Любой клиент должен иметь возможность быстро получить помощь.

---

Любая проблема должна иметь:

```text
Номер

Статус

Ответственного

Историю решения
```

---

# 48. Definition of Done

Helpdesk считается завершенным если:

* клиент может создавать тикеты;
* клиент может отвечать на тикеты;
* работает email-интеграция;
* работает SLA;
* работает база знаний;
* работает история клиента;
* работает отчетность поддержки.

---

# 49. KPI поддержки

Целевые показатели:

```text
Первый ответ < 24 часа

Решение > 90% тикетов

Средняя оценка > 4.5
```

---

# 50. Главная цель

Клиент должен получать качественную поддержку, а владелец платформы должен видеть полную историю взаимодействия, лицензий, платежей и технических проблем в единой системе управления.
