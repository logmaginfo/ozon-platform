# PROJECT C

Admin Financial Dashboard

Версия: 1.0.0

Статус: Financial Analytics Specification

---

# 1. Назначение

Financial Dashboard предназначен для контроля финансовых показателей платформы.

---

Основная цель:

Владелец должен видеть финансовое состояние бизнеса в реальном времени.

---

# 2. Источники данных

```text
Database
```

# 8. MRR

Monthly Recurring Revenue

---

Формула:

```text
Сумма активных лицензий
приведенная к месячному доходу
```

---

Пример:

```text
100 лицензий по 990 ₽/мес

MRR = 99 000 ₽
```

---

# 9. ARR


---

# 37. Definition of Done

Financial Dashboard считается завершенным если владелец способен:

* видеть текущий доход;
* видеть продажи по тарифам;
* видеть активные лицензии;
* видеть истекающие лицензии;
* видеть прогноз дохода;
* видеть возвраты;
* видеть конверсию бизнеса;
* получать финансовые отчеты.

---

# 38. Главная цель

Владелец платформы должен в любой момент понимать:

сколько денег приносит система сейчас,

сколько принесет через месяц,

какие лицензии скоро закончатся,

и какие действия нужно предпринять для роста бизнеса.
